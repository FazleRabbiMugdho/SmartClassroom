## Sequencing rules

1. **No page before its data path.** M4 (ingestion+realtime) gates every feature milestone — build it before safety/weather/vision.
2. **Schemas before database.** P01 Zod schemas inform P02 tables; keep them in sync.
3. **Auth before any UI that shows protected data** — M3 precedes M5+.
4. **Mock device unblocks the whole frontend** so work proceeds without the physical board; firmware-captured fixtures replace mock payloads at integration.
5. **Parallelizable after M4:** M5–M10 depend on M4 but not strictly on each other; M11 depends on events from earlier levels existing.
6. **Each milestone ends** with type-check + lint + relevant tests + a changed-files/behaviour/blockers summary (Part A5).
